# Keyboard, composer and picker reuse

The 23 October 2026 pass keeps the pinned Go/Bubble Tea stack and T3 operation semantics. [Controls](../NATIVE-GO.md#controls) describe the current interface. These design rules apply throughout:

> Avoid unnecessary secondary labels and descriptions. Cut taglines, helper text and secondary labels. If a screen needs them to make sense, fix the layout.

> Make the best decision that will elevate all three: the user experience (UX), developer experience (DX), and agent experience (AX) always, without breaking anything.

AX means agent experience. The implementation removes repeated empty-state, palette, model-status and theme copy. Argument syntax, unavailable reasons, complete request consequences and actionable errors remain because they support a decision.

## Text and recovery contract

The textarea cannot represent every byte sequence unchanged. Tabs, CRLF, literal replacement characters and controls therefore retain the whole attempted input outside it. F5 recalls a rejected attempt into the canonical exact buffer; F4 edits that buffer externally. Sending uses the canonical bytes through the existing session and host journal. Byte/line bounds are checked before insertion, including replacements and combined content. Oversized or invalid UTF-8 editor results keep their unique private file for explicit recovery.

Ctrl+C closes a local surface or preserves the nonempty draft. Ctrl+X explicitly clears only after recovery text is saved. Prompt history is bounded to 24 entries and 512 KiB of text and contains acknowledged prompts, explicit clears and attempted input, never a remote transcript database. A targeted `.prompts.json` compatibility copy uses the same State lock and atomic/fsynced writer, so an older Go client cannot erase recall by rewriting unknown JSON fields. Prepared and committed text survive interrupted publication; a digest identifies the published main state. An unconfirmed staged sent entry becomes an attempted prompt, never an executable retry. Up to 48 entries/1 MiB of protected text may remain during recovery (6 MiB encoded file limit). Preserve that file alongside the Go state when moving or restoring state.

Exact request values and authoritative IDs, generation/action/dialog correlation, synchronous filtering, uncertain-operation journals, Stop's independent lane, explicit same-ID retry and Resolve confirmation remain in their existing owners. No reconnect or client update replays a mutation. The retained Swift client and its separate state are unchanged.

## Verification boundary

Behavioral regressions enter the top-level router and actual Bubble Tea program, including ordinary editor keys, palette reentry, completion/literal paths, exact recovered paste/send, immediate typing after an exact acknowledgment, compact filtered multiselect completion and complete error overlays. Config/client tests cover persistence and unchanged operation semantics. [Verification](verification.md) records actual source, native executable and installed-client evidence separately. No app latency, resource savings or novice usability claim follows from these changes.
